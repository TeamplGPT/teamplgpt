# Contract: `date` 파라미터와 출력

## 1. plugin.json (Location B·D)

`hr-attendance`, `hr-personnel`에 같은 문구(§5.2 형식):

```text
date — 조회 날짜·주 (선택). 사용자가 하루(오늘·어제·10월 15일 등)나 한 주(이번 주·지난주 등)를 말한 경우에만
그 표현을 그대로 전달하고, 이때 year_month는 생략하세요. 형식·되묻기 금지 규칙은 시스템 지시 [HR_SKILL_COMMON]을 따르세요.
{근태: timesheet, work_status, work_calendar, overtime, overtime_limit에서 사용 / 인사: schedule_day·schedule_titles에서만 사용}.
```

examples(Location D): "오늘 출근시각 알려줘" → `{"query_type":"timesheet","date":"오늘"}`, "이번 주 근무현황" → `{"query_type":"work_status","date":"이번 주"}`, "10월 15일 연장근무" → `{"query_type":"overtime","date":"10월 15일"}`, "내일 근무 몇 시부터야" → `{"query_type":"work_calendar","date":"내일"}`. 기존 "2월 27일자 출퇴근 내역 → year_month: '2'" 예시는 `date: "2월 27일"`로 바꾼다. (eval 문장 복사 금지 — 평가 데이터와 다른 문장)

## 2. 시스템 지시 `[HR_SKILL_COMMON]` 4항 (Location E)

"일(day) 정보는 무시하고 월만 전달하세요" → "하루·주를 말하면(오늘·어제·10월 15일·이번 주) 그 표현을 date에 그대로 전달하고 year_month는 생략하세요. date가 없는 skill이면 월만 전달하세요."

## 3. 해석 (`_shared/dateRange.resolveDateRange(value, now)`)

| 입력 | 결과(오늘 2026-10-23 금) |
|---|---|
| 오늘 / 금일 | 20261023~20261023, label "오늘(10/23)" |
| 어제 / 그저께·그제 / 내일 / 모레 | ±일 |
| "10월 15일" / "15일" / "20261015" / "2026-10-15" / "10/15" | 20261015 |
| 이번 주 / 금주 | 20261019~20261025, label "이번 주(10/19~10/25)" |
| 지난주 / 저번 주 | 20261012~20261018 |
| 다음 주 / 차주 | 20261026~20261101 |
| ""·null·"최근"·"전체" | undefined(지정 없음) |
| "저번 분기", "abc" | null → `UNRESOLVED_DATE`(구현 중 변경 — 공통 안내의 "달이나 연도로" 예시가 하루 질문에 맞지 않아 "오늘·어제·10월 15일·이번 주" 예시로. 코드 리뷰 M5) |

추가(2026-10-23 사용자 결정): 요일 표현 "이번 주 수요일"·"지난주 월요일"·"지난 월요일"·"다음 주 금요일"·"수요일"(이번 주) → 그 주의 그 요일 하루, label "이번 주 수요일(10/21)"(D14). 연도 없는 월-일("12월 31일"·"12/31")이 오늘보다 6개월 넘게 뒤면 작년, label "2026년 12월 31일"(D12).

## 4. 출력

- 출퇴근 기록·근무현황: 범위 행만, 끝은 오늘까지. 시작이 오늘 이후 → `> ⚠️ {label}은(는) 아직 지나지 않은 날이라 출퇴근 기록이 없습니다.`(조사는 라벨 앞말 받침으로) 범위 행 0 → `> ⚠️ {label} 출퇴근 기록이 없습니다.` 받은 행의 날짜를 하나도 읽지 못하면 → `> ⚠️ {label} 출퇴근 기록의 날짜를 확인하지 못해 표시하지 않았습니다.`(코드 리뷰 M3)
- 근무현황: 요약 줄은 범위 기준, 월 근무시간 블록 없음.
- 근무캘린더: 범위 행만(미래 허용). 0행 → `> ⚠️ {label} 근무일정이 없습니다.`
- 연장근무: 한도 표 그대로(단 범위가 이번 주 월~일 안이 아니면 "이번 주" 줄을 빼고 이번 달 줄만 — D13) + "### {label} 연장근무 내역" 범위만. 0건 → `> {label} 연장근무 기록이 없습니다.` 시작이 오늘 이후 → 한도 표 + `> ⚠️ {label}은(는) 아직 지나지 않은 날입니다.`
- 인사 일정: 조회 범위 = date 범위.
- 머리에 기간을 알리는 정보 줄을 둔다: `> 조회 날짜: 10월 23일(금)` / `> 조회 기간: 10/19(월) ~ 10/25(일)` — 사용자에게 보이는 줄(018 표 직접 출력).

## 5. 불변

- `date`가 없으면 모든 출력·요청은 지금과 바이트 동일(골든 기준).
