# E2E·실서버 확인 결과 (T035·T039, 2026-10-15)

## 실행 환경

- Postgres `anythingllm-postgres` 기동, AnythingLLM 서버 `SERVER_PORT=3011`
  - 3001은 다른 로컬 프로젝트(notion-cms Next.js)가 점유 중이라 건드리지 않았다.
- runner는 리포 파일을 바꾸지 않고 임시 복사본으로 실행했다.
  - 복사본에서 바꾼 것은 `localhost`→`127.0.0.1` 두 곳(mock 준비 확인, `HR_BASE_URL` override)뿐이다. 사용자가 보관한 로컬 전용 stash와 같은 내용이다.
  - 원인: macOS에서 localhost가 ::1로 풀리는데 mock은 IPv4로만 바인딩한다.
  - 시나리오·mock 내용은 리포와 동일하다. 결과 파일은 임시 폴더의 `runs/` 아래에 있다.
