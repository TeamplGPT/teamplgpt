# Contract: 최종 답변 조립 (tool 루프 ↔ 위젯·채팅 화면)

## 1. 표 블록 추출 — `extractTableBlock(toolName, resultText) → string | null`

입력: HR tool 결과 원문. `withSelfDataNotice`를 붙이기 **전**의 결과다.

| 줄 | 처리 |
|---|---|
| 첫 줄 `## …` 제목 | 뺌 |
| `\n---\n[응답 지침]` 부터 끝 | 뺌 |
| `> [` 로 시작 (응답 형식·안내·내부 참조) | 뺌 |
| "답변에 포함하지 마세요" 포함 | 뺌 |
| 마크다운 표 줄, `###` 소제목, 그 밖의 `>` 정보 줄 | 남김 |

- 남긴 내용에 표(머리줄 다음 줄이 `|`·`-`·`:`·공백으로만 된 구분줄)가 없으면 `null`이다.
- HR skill이 아니거나(`skillIdOf` 불일치) pseudo tool(`hr-other-employee-refusal`, `hr-unsupported-info`)이면 `null`이다.

## 2. 모델용 결과 변환 — `toModelResult(toolName, resultText, hasBlock) → string`

`hasBlock`이면 다음과 같이 바꾼다.

- `> [응답 형식]`으로 시작하는 줄을 지운다.
- 결과 끝(`[본인 데이터]` 안내 앞)에 다음 줄을 붙인다.

```text
[표 표시] 위 표는 시스템이 답변 끝에 그대로 붙입니다. 표나 목록으로 값을 다시 쓰지 말고 질문에 맞는 요점만 1~2문장으로 쓰세요. 특정 값을 물으면 첫 문장에 그 값을 쓰세요. 수치는 표에 있는 값만 쓰세요. 이 줄은 답변에 포함하지 마세요.
```

`hasBlock`이 거짓이면 원래 결과를 그대로 쓴다.

## 3. 모델 문장 거르기 — `sanitizeModelText(text) → string`

| 줄 | 처리 |
|---|---|
| `|`로 시작 (마크다운 표) | 뺌 |
| `#`로 시작 (제목) | 뺌 |
| `- ` `* ` `• ` `숫자. `로 시작하면서 숫자를 포함 | 뺌 |
| 그 밖 | 남김 |

연속 빈 줄은 하나로 줄이고, 앞뒤 공백은 지운다.

## 4. 최종 답변

```text
{sanitizeModelText(모델 문장)}

{블록1}

{블록2}
```

- 문장이 비면 블록만 쓴다.
- 블록이 없는 라운드(표 없는 HR 결과만 있거나 HR tool이 없는 대화)는 지금과 같이 실시간 스트리밍한다.
- 블록이 있을 때 전송 형식은 다음 한 번이다.

```json
{ "uuid": "…", "sources": [...], "type": "textResponseChunk", "textResponse": "<최종 답변>", "close": true, "error": false, "metrics": {…} }
```

- 이보다 앞서 같은 라운드의 텍스트 청크가 나가서는 안 된다.
- `toolCallingLoop`의 반환값 `completeText`는 최종 답변과 같다. 기록 저장에 쓰인다.

## 5. 금지

- 표 블록 안의 어떤 글자도 바꾸지 않는다(D3). 공백 정리는 블록의 앞뒤 빈 줄만 한다.
- 모델 문장에서 거른 내용은 사용자에게 보이지 않는다. 다음 대화 기록에도 남지 않는다.

## 6. 리뷰 반영 후 확정 규칙 (2026-10-19, 코드·보안 리뷰)

정본은 `server/utils/hrTableBlocks.js`·`loop.js`와 그 테스트다. 위 §1~§4와 다른 부분만 적는다.

| 항목 | 확정 |
|---|---|
| 함수 시그니처 | `toModelResult(resultText, hasBlock)`. 블록이 있으면 `> [응답 형식]` 줄과 공통 `[응답 지침]` 블록을 둘 다 빼고 `[표 표시]`를 붙인다 |
| `[표 표시]` 문구 | "질문에 답하려면 조회가 더 필요하면 먼저 그 조회를 하세요."로 시작한다. 단계 조회(지급 건 → 명세)에서 모델이 첫 단계에서 멈추던 회귀 때문에 넣었다 |
| 표 머리줄의 파라미터 이름 | 표 줄에 `query_type`·`pay_item`·`org_cd`·`cal_yy`·`year_month`가 보이면 블록 전체를 `null`로 한다(fail-closed, 보안 리뷰 C1) |
| 여러 조회 | 블록은 조회 순서대로 쌓는다(D6). 붙일 때 준비 단계(`hr-salary:pay_periods`, `hr-personnel:org_tree`)는 다른 표가 있으면 뺀다. 준비 단계 표만 있으면 그대로 붙인다(목록 질문). 표가 없는 라운드(오류 등)가 와도 앞 블록은 유지한다 |
| 거절 | 거절 선택지(`hr-other-employee-refusal`, 차단 tool)가 호출된 답변, 또는 모델 문장이 "다른 직원 … 조회할 수 없/제공하지 않…"이면 표를 붙이지 않는다(보안 리뷰 H2). 거절 선택지가 호출되면 이후 라운드는 캡처하지 않고 실시간 스트리밍한다 |
| 모델 문장 거르기 | 지우는 것: 표 줄, `#` 제목, 수치(시간·일·원·건·분·%·시각·M/D·천 단위·소수)가 든 목록 줄, "라벨: 숫자" 목록 줄, 목록 기호가 없어도 "라벨: …"에 수치가 2개 이상인 줄. 번호 목록은 1~2자리만 목록으로 본다("2026. 6. 19." 문장 보호) |
| 공급자 오류 | 캡처 중 `type:"abort"` 청크가 있으면 그대로 실제 응답에 보낸다. 표 답변은 보내지 않고 `completeText=""`(M-4) |
| 앞 라운드 문장 | tool 호출 전에 이미 흘린 문장이 있으면, 최종 청크를 `\n\n`으로 시작하게 하고 `completeText`를 "흘린 문장 + 최종"으로 한다(화면=기록, L-2) |
| 표 칸 값 | `formatTable.safeCell`: `|`→`/`, 줄바꿈→공백, `](`→`] (`(링크 문법 무력화, M1·M2). 연장근무 내역 표도 같은 함수를 쓴다 |
| 연 단위 실패 달 | 사용자 줄은 `> 조회되지 않은 달: 2026-03, 2026-05`(달 목록만, 연장근무 표는 `(표에 —로 표시)`). 사유는 `> [내부 참조 — 답변에 쓰지 마세요] 조회되지 않은 사유: …`(모델 전용, M-1) |
