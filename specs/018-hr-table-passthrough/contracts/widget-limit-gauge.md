# Contract: 위젯 표 렌더러 — 한도·사용·잔여 (okrservice)

대상 파일:
- `widgets/client/messenger/components/chatbot/MarkdownTable.tsx`
- `markdownTableUtils.ts` (+ 테스트)

## 판정 — `limitTableKind(headers) → 'gauge' | 'monthly' | null`

| 조건 | 결과 |
|---|---|
| 머리글(강조 제거)에 `한도`·`사용`·`잔여`가 모두 있고 첫 머리글이 `구분` | `gauge` |
| 같은 세 머리글이 있고 첫 머리글이 `월` | `monthly` |
| 그 밖 | `null` (기존 렌더) |

## gauge 모드

표 대신 줄마다 블록으로 그린다. 블록 모양은 미리보기 v6과 같다.

```text
{구분}                                   ← 11px, 굵게, 흐린 색
{잔여} 시간 남음                          ← 숫자 26px 굵게 강조색, "시간 남음" 13px
[■■■■■■■■□□□□] (잔여 ÷ 한도, 0~100%)       ← 8px 트랙, 강조색 채움
한도 {한도}시간 중 {사용}시간 사용          ← 11.5px 흐린 색, tabular-nums
```

- 잔여가 0 이하이면 채움 0%, 숫자는 경고색(`#a15c07`), 트랙은 경고 바탕(`#fff4e0`)이다.
- 한도·사용·잔여 중 하나라도 숫자가 아니면 게이지와 큰 숫자를 그리지 않는다. 그 줄은 "{구분}: 한도 {한도} · 사용 {사용} · 잔여 {잔여}" 텍스트로 보인다.
- 접근성: 게이지에 `role="img"`와 `aria-label="{구분} 잔여 {잔여}시간, 한도 {한도}시간 중 {사용}시간 사용"`을 단다.
- 7줄 접기는 해당하지 않는다(한도 표는 1~2줄).

## monthly 모드

표 형태는 그대로 둔다.

- `사용` 칸: 막대 바탕(48px, 강조 연한색) 전체가 그 줄 `한도`이고, 채운 부분이 `사용 ÷ 한도`이다. 그 뒤에 값이 온다.
- **막대 시작점은 모든 줄에서 같아야 한다**(사용자 지적 2026-10-19). 칸을 `[막대 48px][값 고정폭 4.5ch, 오른쪽 정렬]` 두 칸 격자로 그린다. 그러면 "0.0"과 "22.0"처럼 값 길이가 달라도 막대가 밀리지 않는다. 막대가 없는 줄(—, 합계)도 같은 격자를 써서 값 자리를 맞춘다.
- `한도`·`잔여` 칸: 막대 없이 값만 오른쪽 정렬로 보인다.
- 값이 숫자가 아닌 줄(—)과 합계 줄은 막대가 없다.
- **접지 않는다**(최대 12개월 + 합계).

## 테스트

1. gauge: 머리글 `구분|한도|사용|잔여` 2줄 → `data-gauge` 블록 2개, 잔여 텍스트 "8.0 시간 남음", aria-label
2. gauge 음수 잔여 → 채움 0%, 경고색 속성(`data-over="true"`)
3. monthly: 11줄(10개월 + 합계) → 접기 버튼 없음, 사용 칸 `data-usage` 비율 = 사용/한도
4. monthly — 줄 → 막대 없음
5. 머리글이 다른 표 → 기존 렌더(막대·접기) 그대로
