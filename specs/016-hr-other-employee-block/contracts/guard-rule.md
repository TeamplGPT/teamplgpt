# Contract: 공통 시스템 지시 (`server/utils/hrSkillGuard.js` · `hrSkillCommonLines()`)

채팅/query·embed(`hrSkillChatGuard`)와 @agent(`hrSkillPeriodGuard`)가 공유한다. 015 최종본(4항) 위에 즉시 완화 변경(10항·[ORDER]·4항 예시)이 이미 작업 트리에 있다. 이 기능은 10항만 보완한다.

## 10항 — 현재 (즉시 완화, 측정 R2 E4)

```text
10. 다른 직원 정보 요청: 사용자가 본인이 아닌 다른 직원(이름·사번·호칭으로 지칭 — 예: '김기현 연차', '팀장님 급여')의 정보를 물으면 어떤 tool도 호출하지 말고 '다른 직원의 정보는 조회할 수 없어요. 본인 정보는 "내 연차 알려줘"처럼 물어봐 주세요.'처럼 짧게만 답하세요. tool은 항상 본인 데이터만 주므로, 호출하면 본인 데이터를 그 사람 것처럼 잘못 답하게 됩니다. 조직도(조직 구조·조직원 목록)만 예외입니다.
```

## 10항 — 변경 후

```text
10. 다른 직원 정보 요청: 사용자가 본인이 아닌 다른 직원(이름·사번·호칭으로 지칭 — 예: '김기현 연차', '팀장님 급여')의 정보를 묻거나, 팀 휴가자·생일자·남이 올린 결재 문서(내가 결재할 문서·결재한 문서·참조 문서)처럼 다른 직원의 정보를 물으면 어떤 tool도 호출하지 말고 '다른 직원의 정보는 조회할 수 없어요. 본인 정보는 "내 연차 알려줘"처럼 물어봐 주세요.'처럼 짧게만 답하세요(결재 대기 '건수'만 묻는 질문은 todo_count로 답할 수 있습니다). tool은 항상 본인 데이터만 주므로, 호출하면 본인 데이터를 그 사람 것처럼 잘못 답하게 됩니다. 조직도(조직 구조·팀원 이름·소속·직위·직책)만 예외입니다 — 단 특정 직원을 지칭해 묻는 질문은 조직도 항목이어도 거절합니다.
```

## 변경 요지

| 항목 | 이유 |
|---|---|
| 팀 휴가자·생일자·남의 결재 문서 명시 | 지칭 질문만 막으면 "우리 팀 휴가자", "생일자 누구야", "결재할 문서 보여줘"는 남은 tool로 우회 호출될 수 있다 |
| 건수 예외 | 미결 건수는 숫자라 유지(spec D4). 거절 규칙이 건수 질문까지 막지 않게 한다 |
| 조직도 항목 명시 + 지칭 질문 거절 | spec D2·D9 |

## 삭제 — 직원 검색 즉시 호출 줄 (코드 리뷰 반영)


```text
2. skill과 query_type을 정했으면 즉시 tool을 호출하세요. 조회 결과를 추측해 텍스트로만 답하지 마세요. 앞에서 답한 HR 수치의 산정 근거·내역·계산을 다시 묻거나 확인해도('어떻게 나온 거야?', '맞게 계산된 거야?') 대화 기록만 보고 답하지 말고 같은 조회를 다시 호출해 그 결과로만 답하세요.
```
