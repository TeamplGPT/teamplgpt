# Contract: 응답 지침 footer (`ANSWER_GUIDE`)

`_shared/formatTable.js`가 렌더 결과에 부착하는 LLM 대상 소비 규칙의 정본.
문구 변경은 이 파일 갱신 + E2E tier 전건 PASS를 동반해야 한다.

## 정본 문구

```text

---
[응답 지침] 위 표는 조회 데이터이며 그대로 출력하라는 지시가 아닙니다.
- 특정 값을 묻는 질문: 해당 값과 이해에 필요한 맥락만 답변
- 내역·현황을 묻는 질문: 질문과 관련된 행·열만 추려 제시(표 사용 가능)
- 사용자가 전체/상세/표를 명시 요청한 경우: 전체 표 제공
이 지침 문구 자체를 답변에 포함하지 마세요.
```

(선행 개행 포함 — 표 마지막 행과 구분선 분리 보장)

## 부착 규약

| 항목 | 규약 |
|------|------|
| 부착 함수 | `renderWhitelisted()`, `renderTable()` — 반환 문자열 말미 |
| 부착 조건 | 렌더 결과 비어 있지 않을 때만. 0건/오류 안내 문구엔 미부착 (FR-007) |
| 다중 표 응답 | 표마다 부착 허용 — 중복 억제 로직 없음 (research.md R2, fan-out은 L1이 억제) |
| export | `ANSWER_GUIDE` 상수를 `module.exports`에 추가 (검증·재사용용) |
| handler 영향 | 없음 — 7종 handler.js 무수정. 폴백 경로의 "총 N건" 줄이 footer 뒤에 와도 허용 |

## 금지 사항

- 고정 분량 숫자(예: "1~3문장", "최대 5행") 삽입 금지 (FR-001, spec D2)
- footer 원문이 사용자 최종 답변에 노출 금지 (FR-006) — E2E `answer_not_pattern: ["\\[응답 지침\\]"]`로 상시 감시
- skill별 footer 분기 금지 — 7종 공통 단일 상수 (분기 필요 시 스펙 개정)
