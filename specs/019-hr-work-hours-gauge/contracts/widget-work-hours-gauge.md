# Contract: 위젯 근무시간 게이지

okrservice `widgets/client/messenger/components/chatbot/`. 미리보기 A안: https://claude.ai/artifact/Mr1Az7Eer3mV731QskujBd

## 표 판별

`markdownTableUtils.workHoursTable(headers)` — 머리글에 `구분`, `누적 근로`, `월간 소정`, `최대 가능`이 모두 있으면 각 칸 위치를 돌려준다(`소정까지`는 있으면 사용). 아니면 null → 기존 표 렌더.

## 줄마다 게이지 (`WorkHoursGauge.tsx`)

| 요소 | 내용 |
|---|---|
| 제목 | 구분 칸 + " 근무시간" (예: "이번 달(10월) 근무시간") |
| 큰 값 | 누적 근로 칸 문자열 + "시간 근로" |
| 막대 | 기준 길이 = 최대 가능. 채움 = 누적/최대(최대 100%). 소정 위치 세로선 = 소정/최대. 소정 뒤 빈 구간은 빗금(연장 가능 구간) |
| 소정 초과 | 누적 > 소정이면 소정 위치까지 기본색, 그 뒤 주황 |
| 눈금 글자 | 왼쪽 `0`, 세로선 아래 `소정 {월간 소정}`, 오른쪽 `최대 {최대 가능}` |
| 아래 줄 | 소정까지 칸이 숫자면 "월간 소정 {소정}시간 중 {누적}시간 · 소정까지 {소정까지}시간", 아니면 "월간 소정 {소정}시간 · 최대 가능 {최대}시간" |
| 범례 | 소정 초과가 있을 때만 "소정 근로 / 소정 초과" |
| 값 없음 | 누적 근로 또는 월간 소정 칸이 숫자가 아니면 막대 없이 큰 값 "—" + "근무시간을 조회하지 못했습니다." |
| 최대 없음 | 최대 가능이 숫자가 아니면 막대 기준을 그릴 수 없으니 막대 없이 큰 값과 아래 줄만 |
| 접근성 | 막대에 `role="img"`, `aria-label="{구분} 누적 근로 {누적}시간, 월간 소정 {소정}시간, 최대 가능 {최대}시간"` |
| 위치 계산 | `workHoursGeometry(누적, 소정, 최대)` — 모든 위치를 최대 가능 기준으로 잰다. `split`(채움 안에서 주황 시작 %) = 소정 위치 ÷ 채움 위치(019 코드 리뷰 M-1: 누적이 최대를 넘어도 주황은 소정 세로선에서 시작) |
| 테스트 훅 | `data-work-hours`(게이지), 막대 `data-fill`·`data-normal`·`data-split`(정수 %), `data-over="true"`(소정 초과) |

숫자는 표에 적힌 문자열을 그대로 보여준다(위젯은 비율 계산에만 숫자로 읽는다). 표 아래 `> ` 정보 줄(단위 안내)은 기존처럼 그대로 보인다.
